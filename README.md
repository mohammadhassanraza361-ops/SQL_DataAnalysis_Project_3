# SQL_Data_Analysis_Project_3:

This project demonstrates my SQL skills by analyzing a retail sales dataset using MySQL. The goal is to answer real-world 
business questions and generate meaningful insights from the data.

# Key Features:
1. Database creation
2. Table design.
3. Data analysis using SQL queries.
4. SELECT Statement.
5. Filtering with WHERE.
6. Sorting using ORDER BY.
7. GROUP BY.
8. Aggregate functions (SUM, COUNT, AVG etc.).
9. Business insights such as Total sales, Total revenue and Category Performance.

This project helped me improve my SQL querying, data analysis, and problem-solving skills by working with a practical 
E-commerce dataset . It reflects my ability to use SQL to extract, analyze, and present data-driven insights that support
business decision-making.
